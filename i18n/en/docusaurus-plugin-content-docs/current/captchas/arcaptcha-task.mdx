# ARCaptcha

<PriceBlockWrap>
  <PriceBlock title="ARCaptcha" captchaId="arcaptcha"/>
</PriceBlockWrap>

<McpNotice />

ARCaptcha is a privacy-focused captcha system that protects websites from automated actions. It offers three challenge types: Hidden Captcha, Puzzle Captcha, and Classic Captcha.

## Request parameters

<div className="bordered-panel">
    <ParamItem title="type" required type="string" />
    **ArCaptchaTask**

    ---

    <ParamItem title="class" required type="string" />
    **alibaba**

    ---

    <ParamItem title="websiteURL" required type="string" />
    The address of the main page where the captcha is located.

    ---

    <ParamItem title="websiteKey" required type="string" />
    The value of the siteKey parameter found on the page.

    ---

    <ParamItem title="isInvisible" type="boolean" />
    `true` if the captcha is invisible, meaning it has a hidden verification field. When bot activity is suspected, additional verification is triggered.

    ---

    <ParamItem title="userAgent" type="string" />
    Browser User-Agent. Use the current value supported by CapMonster Cloud: `userAgentPlaceholder`<br />

You can get the latest value at: [https://capmonster.cloud/api/useragent/actual](https://capmonster.cloud/api/useragent/actual).

</div>

## How to find the websiteKey

1. Open the page with ARCaptcha.
2. Open **Developer Tools** (**F12** or right-click → **Inspect**).
3. Go to the **Network** tab and reload the page.
4. Look for a request to a URL containing `/api.js` with parameters.
5. Find the `site_key` parameter in the request URL or check the HTML for the ARCaptcha widget configuration.

Alternatively, search the page source code for `site_key` or `sitekey` in script tags or widget initialization code.

## How to find the apiJsUrl

1. In **Developer Tools**, go to the **Network** tab.
2. Filter requests to find the ARCaptcha script (usually a file named `api.js`).
3. Copy the full URL of this script, including all query parameters.
