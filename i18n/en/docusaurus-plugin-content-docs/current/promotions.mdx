## Bonuses for Solved Task Volume

The bonus amount depends on the amount spent on CAPTCHA recognition in CapMonster Cloud over the past 30 days:

* from $500 — 5% bonus;
* from $1,000 — 10% bonus;
* from $10,000 — 15% bonus.

Once a bonus tier is reached, the bonus is automatically added to every balance top-up and remains valid for 30 calendar days.
If your spending volume reaches the next tier, the bonus amount will increase automatically.

## Trial Balance for New Users

New CapMonster Cloud users can receive a $0.1 trial balance to test the service on real tasks.

To receive the trial funds, contact [technical support](https://helpdesk.zennolab.com/en-us/conversation/new) and specify the email address registered to your account.

## Bonus for New ZennoLab Product Users

A $5 bonus for testing CapMonster Cloud is provided with the first purchase of [ZennoLab](https://zennolab.com/en/) products totaling $5 or more.

The bonus is credited automatically and only if you have not previously used the CapMonster Cloud service.

To verify that the funds have been credited successfully, log in to the [capmonster.cloud](https://dash.capmonster.cloud/) dashboard using the same email address and password that you used when purchasing ZennoLab products on the [zennolab.com](https://zennolab.com) website.

The offer will be especially useful for users of [ZennoPoster](https://zennolab.com/en/products/zennoposter/), an application for automating routine actions in a web browser. To use the bonus, follow these steps:

1. Copy the API key from the [dashboard](https://dash.capmonster.cloud).
2. Paste the API key into ZennoPoster: **Edit** > **Settings** > **CAPTCHAs** > **CapMonster Cloud** module > **Secret Key** field.
3. Move the cursor to the **Balance** field. Your current account balance should then be displayed.
