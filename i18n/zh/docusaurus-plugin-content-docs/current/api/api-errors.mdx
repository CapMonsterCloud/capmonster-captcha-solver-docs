# 错误说明

:::info 防止错误的建议
<div style={{color: "#000"}}>

提交任务前：

- 请确保所需的 CAPTCHA 类型受 CapMonster Cloud 支持。如果当前尚不支持所需类型，请联系我们——我们会考虑添加相应支持；
- 使用最新的 API 参数；
- 使用代理时，请确认代理可用且连接稳定。

如果错误仍然存在，请通过[表单](https://helpdesk.zennolab.com/zh-cn/conversation/new)、[网站](https://capmonster.cloud/)或[文档](https://docs.capmonster.cloud/)中的聊天，或通过 [Telegram 频道](https://t.me/capmonstercloud) 联系支持。

联系支持时，请提供 `taskId`、任务类型（`type`）、原始输入数据或图片、任务日期和时间，以及在可能的情况下提供请求正文。

</div>
:::

<span style={{fontSize: '1.5rem'}}>**重新发送请求**</span>

<br />某些错误可能是临时性的。在这种情况下，可以稍后重试请求，或创建新的任务——具体建议请参见对应错误的说明。

如果错误与 API 密钥、余额、任务参数、代理、令牌或其他输入数据有关，请在重新发送请求前检查并修正相应值。

重试请求时，请遵循建议的请求间隔，并在必要时增加重试之间的等待时间。

### `INVALID KEY`
API 错误代码: `ERROR_KEY_DOES_NOT_EXIST` <br />
未找到 API 密钥或格式不正确。请确认您使用的是[个人账户](https://dash.capmonster.cloud/)中的密钥，并且该密钥处于激活状态。如果错误仍然存在，请联系支持并提供 *taskId* 和完整请求。

### `INVALID CHARACTER`
API 错误代码: `ERROR_PROXY_CREDENTIALS_INVALID_CHARACTER` <br />
代理的登录名或密码包含无效字符 `%`。请删除该字符后重新填写代理凭据并重试请求。

### `NO FUNDS`
API 错误代码: `ERROR_ZERO_BALANCE` <br />
账户余额不足以进行识别。[充值](https://capmonster.cloud/SelectPaymentType) 后重试任务。

### `BIG IMAGE SIZE`
API 错误代码: `ERROR_TOO_BIG_CAPTCHA_FILESIZE` <br />
上传的图片超过允许的 50 KB 大小。请降低分辨率或压缩文件后重新提交任务。此错误仅出现在需要上传图片的 CAPTCHA 中（*ImageToText、ComplexImageTask、ComplexImageTask Recaptcha* 等）。

### `ZERO IMAGE SIZE`
API 错误代码: `ERROR_ZERO_CAPTCHA_FILESIZE` <br />
图片大小过小（小于 100 字节）。请检查文件是否正确并包含 CAPTCHA 图片。

### `CAPTCHA ID IS NOT FOUND`
API 错误代码: `ERROR_NO_SUCH_CAPCHA_ID`, `WRONG_CAPTCHA_ID` <br />
请检查 `taskId` 的值。如果任务不存在、结果保存期限已过或标识符格式不正确，可能会出现此错误。使用相同的 `taskId` 重试请求不会返回结果。

### `CAPTCHA UNSOLVABLE`
API 错误代码: `ERROR_CAPTCHA_UNSOLVABLE` <br />
无法解决 CAPTCHA。通常这是临时错误——请尝试重新创建任务。同时，请检查请求参数是否正确且为最新值。

对于图像类 CAPTCHA，如果反复出现错误，可能表示图像无法被正确识别：图像可能包含过多噪声、已损坏，或不包含有效答案。

未解决的任务不会收费。

### `CAPTCHA IS NOT READY`
API 错误代码: `CAPTCHA_NOT_READY` <br />
任务仍在处理中。请稍后再次调用 [getTaskResult](./methods/get-task-result.mdx)，两次请求之间至少间隔 2 秒。

### `REQUEST IS NOT ALLOWED FROM YOUR IP`
API 错误代码: `ERROR_IP_NOT_ALLOWED` <br />
当前 IP 使用此密钥的请求被拒绝。请在个人账户的设置中[将您的 IP 添加到白名单](https://dash.capmonster.cloud/Account/Settings)。

### `IP BANNED`
API 错误代码: `ERROR_IP_BANNED` <br />
由于大量无效请求，该 IP 地址已被临时封锁。请检查请求是否正确，并稍后重试。收到此错误后不要立即重复发送请求。

### `INCORRECT METHOD`
API 错误代码: `ERROR_NO_SUCH_METHOD` <br />
任务类型（参数 *type*）不正确。请检查支持的[验证码类型列表](https://docs.capmonster.cloud/zh/docs/captchas/)（参数 *type* 的值）。

### `REQUEST LIMIT EXCEEDED`
API 错误代码: `ERROR_TOO_MUCH_REQUESTS` <br />
已超出允许的请求限制。请增加重复请求之间的间隔后再试。获取任务结果时，请不要超过每 2 秒调用一次 [getTaskResult](./methods/get-task-result.mdx)。

### `THE DOMAIN IS NOT ALLOWED`
API 错误代码: `ERROR_DOMAIN_NOT_ALLOWED` <br />
CapMonster Cloud 禁止识别来自某些域名的 CAPTCHA。当尝试为这些域名创建任务时，将会收到此错误。

### `THE TOKEN IS EXPIRED`
API 错误代码: `ERROR_TOKEN_EXPIRED` <br />
提交的 token 或 challenge 已过期。请获取最新值并创建新的任务。使用相同数据重新提交任务会再次产生相同错误。

### `INVALID RECAPTCHA SITEKEY`
API 错误代码: `ERROR_RECAPTCHA_INVALID_SITEKEY` <br />
提供的 *websiteKey* 不正确。请检查 CAPTCHA 页面代码中的值并正确传递。如果难以找到正确的 key，请联系支持。

### `INVALID RECAPTCHA DOMAIN`
API 错误代码: `ERROR_RECAPTCHA_INVALID_DOMAIN` <br />
域名与指定的 *sitekey* 不匹配，或参数 *websiteURL* 格式错误。请提供包含协议的完整 CAPTCHA 页面 URL。**仅支持 `http://` 和 `https://`。**

### `RECAPTCHA TIMEOUT`
API 错误代码: `ERROR_RECAPTCHA_TIMEOUT` <br />
reCAPTCHA 解决超时。请创建新的任务。如果使用自有代理时此错误反复出现，请检查代理的速度和可用性，或更换其他代理。

### `YOUR IP IS BLOCKED`
API 错误代码: `ERROR_IP_BLOCKED` <br />
由于大量失败请求，该 IP 被封锁。请在重新提交前检查任务参数和 API 密钥。

### `FAILED TO CONNECT PROXY`
API 错误代码: `ERROR_PROXY_CONNECT_REFUSED` <br />
代理服务器拒绝连接。请检查 IP 地址、端口和代理可用性，或更换其他代理。

### `THE PROXY IP IS BANNED`
API 错误代码: `ERROR_PROXY_BANNED` <br />
指定的代理已被目标网站封锁。请使用其他代理。

### `MISSING PROXY`
API 错误代码: `ERROR_PROXY_MISSING`<br />
缺少必填的代理参数或 *proxyType* 错误。请填写所有必填参数：*proxyType*、*proxyAddress*、*proxyPort*，并检查 *proxyType* 的值是否正确。

### `PROXY NOT AUTHORIZED`
API 错误代码: `ERROR_PROXY_NOT_AUTHORISED`<br />
代理身份验证信息错误：*proxyLogin* 或 *proxyPassword*。请检查 *proxyLogin* 和 *proxyPassword*，确保其正确且有效。

### `PROXY READ TIMEOUT`
API 错误代码: `ERROR_PROXY_READ_TIMEOUT`<br />
使用代理时等待响应超时。请重试请求。如果错误经常出现，请检查代理的可用性和稳定性，或更换其他代理。

### `INCORRECT TASK TYPE`
API 错误代码: `ERROR_TASK_NOT_SUPPORTED` <br />
任务类型不受支持或不正确。请检查任务对象中的 type 属性值。

### `TASK ABSENT`
API 错误代码: `ERROR_TASK_ABSENT` <br />
在 [createTask](./methods/create-task.mdx) 请求中缺少 task 对象或 JSON 无效。请检查请求结构。

### `USERAGENT IS EXPIRED`
API 错误代码: `ERROR_WRONG_USERAGENT`<br />
请求中提供的 User Agent 无效。您可以在[这里](https://capmonster.cloud/api/useragent/actual)查看最新的 User Agent。

### `SERVICE NOT AVAILABLE`
API 错误代码：`ERROR_SERVICE_NOT_AVAILABLE`<br />
服务暂时不可用。当回调（callback）服务不可用，或 [getTaskResult](./methods/get-task-result.mdx) 可用性检查失败时，将返回此错误。为了避免用户为无法获取结果的任务付费，在这些情况下将禁止创建新任务。请稍后重试请求。如果使用了 callback，请确保指定的回调 URL 可以正常访问。

### `INVALID TASK`
API 错误代码：`ERROR_INVALID_TASK`<br />
请求在语法上是正确的，但包含无法创建任务的无效数据。例如，必填字段缺失、字段值错误或数据已过期，导致无法完成 CAPTCHA 识别。`errorDescription` 字段会说明哪些请求字段存在问题以及如何修正。请检查任务参数，确认提交的数据仍然有效，并根据 `errorDescription` 修正相应字段。如果仍无法自行解决问题，请联系[技术支持](https://helpdesk.zennolab.com/zh-cn/conversation/new)。
