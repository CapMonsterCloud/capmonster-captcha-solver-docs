## 已解决任务量奖励

奖励金额取决于您在过去 30 天内在 CapMonster Cloud 中用于 CAPTCHA 识别的消费金额：

* 满 $500 — 5% 奖励；
* 满 $1,000 — 10% 奖励；
* 满 $10,000 — 15% 奖励。

达到奖励等级后，奖励将自动添加到每次余额充值中，并在 30 个自然日内有效。
如果您的消费金额达到下一等级，奖励金额将自动增加。

## ZennoLab 产品新用户奖励

首次购买总金额不低于 $5 的 [ZennoLab](https://zennolab.com/zh/) 产品时，可获得 $5 的 CapMonster Cloud 测试奖励。

该奖励将自动计入您的账户，但仅限此前未使用过 CapMonster Cloud 服务的用户。

要确认资金是否已成功到账，请使用您在 [zennolab.com](https://zennolab.com) 网站购买 ZennoLab 产品时所用的相同电子邮件地址和密码，登录 [capmonster.cloud](https://dash.capmonster.cloud/) 控制面板。

该优惠尤其适合 [ZennoPoster](https://zennolab.com/zh/products/zennoposter/) 用户。ZennoPoster 是一款用于在 Web 浏览器中自动执行例行操作的应用程序。要使用该奖励，请按以下步骤操作：

1. 在[控制面板](https://dash.capmonster.cloud)中复制 API 密钥。
2. 将 API 密钥粘贴到 ZennoPoster：**编辑** > **设置** > **验证码** > **CapMonster Cloud** 模块 > **代码**字段。
3. 将光标移至**余额**字段。随后应显示您账户的当前余额。
