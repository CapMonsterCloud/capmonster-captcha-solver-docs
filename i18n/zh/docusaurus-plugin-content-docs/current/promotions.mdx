## 已完成任务量奖励

根据您在过去一个月内于 CapMonster Cloud 解决的 CAPTCHA 数量，获得余额奖励*。满足条件后，奖励将立即计入您的余额：

* 每月 $500 起：5% 奖励
* 每月 $1000 起：10% 奖励
* 每月 $10000 起：15% 奖励

例如，您在 16 日开始解决 CAPTCHA。一个月后，我们会评估您在上一周期内解决的 CAPTCHA 数量。如果满足促销活动条件，相应的奖励将计入您的余额。

\* *一个月按 30 个自然日计算*

## 面向 CapMonster Cloud 新用户的初始充值

CapMonster Cloud 新用户可获得 $0.1 的小额初始余额，足以使用您的真实任务测试服务。

如需获得奖励，请联系[技术支持](https://helpdesk.zennolab.com/zh-cn/conversation/new)，并提供与您账户关联的电子邮件地址。

## 面向 ZennoPoster Pro 和 ZennoLab 产品新用户的奖励

购买 [ZennoPoster Pro](https://zennolab.com/en/products/zennoposter/) 的用户可获得 $5 奖励，用于测试 CapMonster Cloud。

此外，首次购买金额超过 $5 的 [ZennoLab](https://zennolab.com/zh/) 产品用户也将获得相同的奖励。

奖励将自动计入余额，但仅限此前未使用过 CapMonster Cloud 服务的用户。

我们邀请软件开发者和所有者参与我们的联盟计划。您可以获得受推荐用户 CAPTCHA 绕过支出**最高 30%**的佣金。
