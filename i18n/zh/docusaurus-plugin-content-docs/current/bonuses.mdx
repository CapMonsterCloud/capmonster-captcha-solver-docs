# 奖励与忠诚度计划

CapMonster Cloud 为新用户、长期用户、其他 ZennoLab 产品的用户，以及开发者和软件所有者提供多种奖励计划。

## <img src={newUserBonus} alt="" width="50" height="50" style={{ verticalAlign: 'middle', marginRight: '1px' }} />新用户

注册 CapMonster Cloud 后，您可以获得 **$0.1（10 美分）的测试余额，用于体验服务**。

要获得测试资金：

1. 注册 [CapMonster Cloud](https://dash.capmonster.cloud)。
2. 联系[技术支持](https://helpdesk.zennolab.com/zh-cn/conversation/new)，或发送邮件至 [support@capmonster.cloud](mailto:support@capmonster.cloud)。
3. 提供您账户所使用的电子邮箱地址。

:::warning 重要：
使用临时邮箱注册的账户无法获得测试奖励。
:::

## <img src={loyaltyBonus} alt="" width="50" height="50" style={{ verticalAlign: 'middle', marginRight: '1px' }} />长期用户

长期用户在充值余额时最高可获得 **15% 的额外奖励**。

奖励比例取决于您在过去 30 天内通过 CapMonster Cloud 识别 CAPTCHA 的消费金额：

| 过去 30 天的消费金额 | 充值奖励 |
| ------------------- | -------: |
| $500 起             |       5% |
| $1,000 起           |      10% |
| $10,000 起          |      15% |

达到相应等级后，奖励会自动应用于每次余额充值，并在 **30 个自然日**内有效。

### 如何计算最近 30 天

计算采用滚动 30 天周期，而不是按自然月计算。

这意味着消费金额不是按每月 1 日至月末统计，而是统计当前日期之前连续 30 天内的消费。

例如，如果您从 **8 月 16 日**开始大量识别 CAPTCHA，那么在 **9 月 16 日**，系统会检查您此前 30 天的消费金额。如果在此期间达到某个奖励等级，相应比例的奖励将应用于您的余额充值。

达到奖励等级后，该奖励会自动应用于每次余额充值，并在 **30 个自然日**内有效。

如果您在此期间的消费达到下一个等级，奖励比例将自动提高。

## <img src={zennolabProductsBonus} alt="" width="50" height="50" style={{ verticalAlign: 'middle', marginRight: '1px' }} />其他 ZennoLab 产品的用户

如果您已经在使用 ZennoLab 的产品，例如 **ZennoPoster**、**ZennoDroid** 或公司的其他产品，则可以获得 **$5 的 CapMonster Cloud 余额**。

满足以下条件时，奖励会自动发放：

* 您拥有 ZennoLab 账户；
* 您之前曾在 [ZennoLab 个人账户](https://account.zennolab.com/personal-area-main/my-products)中购买产品或订阅，金额超过 **$5**；
* 您使用同一个 ZennoLab 账户登录 CapMonster Cloud。

例如，如果您之前购买过一个月、六个月或一年的 ZennoPosterPro 订阅，之后首次使用相同的账户凭据登录 CapMonster Cloud，奖励将自动添加到您的 CapMonster Cloud 余额中。

:::info ZennoLab 和 CapMonster Cloud 使用同一个账户
`account.zennolab.com` 和 `capmonster.cloud` 使用统一账户。

如果您已经拥有 ZennoLab 账户，则无需在 CapMonster Cloud 中再次注册。请使用相同的账户凭据或同一个 Google 账户登录 CapMonster Cloud。

如果您尝试使用已被使用的电子邮箱再次注册，系统会提示该邮箱已存在。
:::

*有关如何将 CapMonster Cloud 连接到不同程序的详细说明，请参阅[如何将 CapMonster Cloud 连接到所需程序？](./external-services/external-program.mdx)*

## <img src={developerBonus} alt="" width="60" height="60" style={{ verticalAlign: 'middle', marginRight: '1px' }} />开发者和软件所有者

开发者和软件所有者最高可获得 **被推荐用户用于 CAPTCHA 识别支出的 30%**。

合作条件将根据具体情况单独确定。

要了解适用于您的合作条件：

* 在 [CapMonster Cloud 网站](https://capmonster.cloud/zh/)填写表单；
* 发送邮件至 [support@capmonster.cloud](mailto:support@capmonster.cloud)；
* 或联系 [ZennoLab 技术支持](https://helpdesk.zennolab.com/zh-cn/conversation/new)。
