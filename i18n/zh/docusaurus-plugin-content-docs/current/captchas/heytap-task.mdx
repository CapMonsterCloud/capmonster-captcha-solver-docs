# HeyTap

<PriceBlockWrap>
  <PriceBlock title="HeyTap" captchaId="proton"/>

<McpNotice />

HeyTap Captcha 是一个安全系统，用于保护网站免受自动化操作的影响。它分析用户行为并生成令牌以确认合法活动。

	<MethodItem>

    </MethodItem>

```json
{
  "clientKey": "API_KEY",

    "type": "CustomTask",

  }
```

## 如何找到 websiteKey

1. 打开带有 HeyTap Captcha 的页面。
2. 打开**开发者工具**（**F12** 或右键点击 → **检查**）。
3. 转到 **Network**（网络）选项卡并重新加载页面。
4. 查找包含 HeyTap 验证码 API 的 URL 请求（通常是发往 `heytapmobi.com` 的请求）。
5. URL 中的 `ak` 参数就是 `websiteKey`。

或者，在页面源代码中搜索与 HeyTap 相关的初始化参数或配置对象。

## 如何找到 apiServer

1. 在**开发者工具**中，转到 **Network**（网络）选项卡。
2. 查找发往以 `heytapmobi.com` 结尾的域名的请求。
3. 复制子域（例如，`captcha-sec.heytapmobi.com`）。
4. 将此值传递到 `metadata.apiServer` 字段，不包括 `https://` 前缀。
