## 获取音频并转换为 Base64

1. 打开包含验证码的页面并启动 **DevTools**，然后转到 **Network** 选项卡。
2. 单击相应按钮启用验证码的音频模式。
3. 在请求列表中找到以下格式的地址：
   `blob:https://example.com/3be79ac6-1b3d-43ef-9a8a-7ad8877b3606`
4. 复制此 URL 并在浏览器地址栏中打开，即可打开 **.wav** 格式的验证码音频文件。

![](../images/ComplexImageTask-Recognition/bills_audio4.png)

![](../images/ComplexImageTask-Recognition/bills_audio3.png)

5. 保存该文件，并使用任意方式将 **.wav** 文件转换为 **Base64** —— 例如使用 Node.js：

```JavaScript
const fs = require("fs");

// 源 .wav 文件路径
const filePath = "C:\\Users\\User\\Downloads\\file-acbe-4fb3-9f8e-f989ba6c7fde.wav";

const fileBuffer = fs.readFileSync(filePath);

// 转换为 Base64
const base64 = fileBuffer.toString("base64");

// 将 Base64 字符串保存到文本文件
fs.writeFileSync("output.txt", base64);

console.log("文件已成功转换为 Base64，并保存为 output.txt");
```

6. 将生成的 Base64 字符串用于 CapMonster Cloud 的任务请求中。
