# FengkongCloud

<PriceBlockWrap>
  <PriceBlock title="FengkongCloud" captchaId="fengkongcloud"/>
</PriceBlockWrap>

<McpNotice />

FengkongCloud é uma solução de captcha que protege sites contra ações automatizadas. Ele analisa o comportamento do usuário e gera um token que confirma a atividade legítima.

    <ParamItem title="class" required type="string" />

    <ParamItem title="websiteURL" required type="string" />

    <ParamItem title="websiteKey" required type="string" />

## Como encontrar o websiteKey

1. Abra a página com o captcha FengkongCloud.
2. Abra as **Ferramentas do Desenvolvedor** (**F12** ou clique com o botão direito → **Inspecionar**).
3. Vá para a guia **Network** e recarregue a página.
4. Procure por uma solicitação para uma URL contendo `/conf` com parâmetros como `appid` ou `organization`.
5. O valor do parâmetro `appid` é o `websiteKey`.

Alternativamente, pesquise no código-fonte da página por `appid` ou procure scripts carregados de domínios `fengkongcloud.com`.

## Como encontrar o apiJsUrl

1. Nas **Ferramentas do Desenvolvedor**, vá para a guia **Network**.
2. Filtre as solicitações para encontrar o script carregado de `castatic.fengkongcloud.com`.
3. Procure por um arquivo chamado `smcp.min.js` e copie sua URL completa.
