## Bônus por Volume

Receba um bônus adicionado ao seu saldo de presentes a cada depósito, com base no volume de CAPTCHAs resolvidos no CapMonster Cloud. O bônus é válido por 30 dias corridos a partir do momento em que as condições forem atendidas:

* A partir de US$ 500/mês: bônus de 5%
* A partir de US$ 1.000/mês: bônus de 10%
* A partir de US$ 10.000/mês: bônus de 15%

---

## Depósito Inicial para Novos Usuários do CapMonster Cloud

Novos usuários do CapMonster Cloud recebem um pequeno saldo inicial de US$ 0,1, suficiente para testar o serviço em tarefas reais. Para solicitá-lo, entre em contato com o [suporte técnico](mailto:support@capmonster.cloud?subject=Starter%20deposit%20for%20a%20new%20CapMonster%20Cloud%20user).

---

## Bônus para Novos Usuários do ZennoPoster Pro

Quem adquirir o [ZennoPoster Pro](https://zennolab.com/en/products/zennoposter/) recebe um bônus de US$ 5 para testar o CapMonster Cloud. Esse depósito é suficiente, por exemplo, para resolver 5.000 desafios reCAPTCHA v2 Enterprise ou aproximadamente 3.800 desafios Cloudflare.

O bônus é creditado automaticamente.
