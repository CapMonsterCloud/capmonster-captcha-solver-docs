## Bônus pelo Volume de Tarefas Resolvidas

Receba um bônus no saldo com base no volume de CAPTCHAs resolvidos no CapMonster Cloud durante o último mês*. O bônus é creditado assim que as condições são atendidas:

* a partir de $500/mês: bônus de 5%
* a partir de $1000/mês: bônus de 10%
* a partir de $10000/mês: bônus de 15%

Por exemplo, você começou a resolver CAPTCHAs no dia 16. Um mês depois, avaliamos o volume de CAPTCHAs que você resolveu durante o período anterior. Se as condições da promoção forem atendidas, o bônus correspondente será creditado no seu saldo.

\* *Um mês é considerado como 30 dias corridos*

## Depósito Inicial para Novos Usuários do CapMonster Cloud

Novos usuários do CapMonster Cloud recebem um pequeno saldo inicial de $0.1, suficiente para testar o serviço em suas tarefas reais.

Para receber o bônus, entre em contato com o [suporte técnico](https://helpdesk.zennolab.com/en-us/conversation/new) e informe o endereço de e-mail associado à sua conta.

## Bônus para Novos Usuários do ZennoPoster Pro e de Produtos ZennoLab

Quem adquirir o [ZennoPoster Pro](https://zennolab.com/en/products/zennoposter/) recebe um bônus de $5 para testar o CapMonster Cloud.

Além disso, usuários de produtos da [ZennoLab](https://zennolab.com/en/) que realizarem sua primeira compra acima de $5 também receberão o mesmo bônus.

O bônus é creditado automaticamente e somente se você não tiver utilizado o serviço CapMonster Cloud anteriormente.

Convidamos desenvolvedores e proprietários de software a participar do nosso programa de afiliados. Você pode ganhar **até 30%** dos gastos com bypass de CAPTCHA dos usuários indicados.

Para obter condições mais detalhadas, use o [formulário de feedback](https://helpdesk.zennolab.com/en-us/conversation/new) e especifique **Request topic** como "Partnership offer".
