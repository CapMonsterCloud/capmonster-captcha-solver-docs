## Bônus por Volume de Tarefas Resolvidas

O valor do bônus depende do valor gasto com o reconhecimento de CAPTCHA no CapMonster Cloud nos últimos 30 dias:

* a partir de $500 — bônus de 5%;
* a partir de $1.000 — bônus de 10%;
* a partir de $10.000 — bônus de 15%.

Após atingir um nível de bônus, o bônus é adicionado automaticamente a cada recarga de saldo e permanece válido por 30 dias corridos.
Se o volume de seus gastos atingir o próximo nível, o valor do bônus aumentará automaticamente.

## Saldo de Teste para Novos Usuários

Novos usuários do CapMonster Cloud podem receber um saldo de teste de $0.1 para testar o serviço em tarefas reais.

Para receber os créditos de teste, entre em contato com o [suporte técnico](https://helpdesk.zennolab.com/en-us/conversation/new) e informe o endereço de e-mail cadastrado em sua conta.

## Bônus para Novos Usuários dos Produtos ZennoLab

Um bônus de $5 para testar o CapMonster Cloud é concedido na primeira compra de produtos [ZennoLab](https://zennolab.com/en/) no valor total de $5 ou mais.

O bônus é creditado automaticamente e somente se você não tiver usado o serviço CapMonster Cloud anteriormente.

Para verificar se os créditos foram adicionados com sucesso, acesse o painel do [capmonster.cloud](https://dash.capmonster.cloud/) usando o mesmo endereço de e-mail e senha utilizados na compra dos produtos ZennoLab no site [zennolab.com](https://zennolab.com).

A oferta será especialmente útil para usuários do [ZennoPoster](https://zennolab.com/en/products/zennoposter/), um aplicativo para automatizar ações rotineiras em um navegador web. Para usar o bônus, siga estas etapas:

1. Copie a chave de API no [painel](https://dash.capmonster.cloud).
2. Cole a chave de API no ZennoPoster: **Edit** > **Settings** > **CAPTCHAs** > módulo **CapMonster Cloud** > campo **Secret Key**.
3. Mova o cursor para o campo **Balance**. Em seguida, o saldo atual da sua conta deverá ser exibido.

Convidamos desenvolvedores e proprietários de software a participar do nosso programa de parcerias. Você pode ganhar até 30% dos gastos dos usuários indicados com a resolução de CAPTCHA.

Para obter condições mais detalhadas, use o [formulário de feedback](https://helpdesk.zennolab.com/en-us/conversation/new) e informe **Request topic** como "Partnership offer".
