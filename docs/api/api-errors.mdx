# Описание ошибок

:::info Рекомендации по предотвращению ошибок
<div style={{color: "#000"}}>

Перед отправкой задачи:

- убедитесь, что используемый тип CAPTCHA поддерживается CapMonster Cloud. Если нужного типа нет среди поддерживаемых, сообщите нам об этом — мы рассмотрим возможность добавить его поддержку;
- используйте актуальные параметры API;
- при работе с прокси проверьте их доступность и стабильность.

Если ошибка сохраняется, обратитесь в поддержку через [форму](https://helpdesk.zennolab.com/ru/conversation/new), чат [на сайте](https://capmonster.cloud/) или в [документации](https://docs.capmonster.cloud/), либо через [Telegram-канал](https://t.me/capmonstercloud).

При обращении укажите `taskId`, тип задачи (`type`), исходные данные или изображение, дату и время задачи и, если возможно, тело запроса.

</div>
:::

<span style={{fontSize: '1.5rem'}}>**Повторная отправка запросов**</span>


<br />Некоторые ошибки являются временными. В таких случаях запрос можно повторить через некоторое время или создать новую задачу — рекомендуемое действие указано в описании соответствующей ошибки.

Если ошибка связана с API-ключом, балансом, параметрами задачи, прокси, токеном или другими входными данными, проверьте и исправьте соответствующие значения перед повторной отправкой запроса.

При повторных попытках соблюдайте рекомендуемые интервалы между запросами и при необходимости увеличивайте задержку.

### `INVALID KEY`
Код ошибки в API: `ERROR_KEY_DOES_NOT_EXIST` <br />
API-ключ не найден или указан в неверном формате. Проверьте, что вы используете ключ из [личного кабинета](https://dash.capmonster.cloud/) и он активен. Если ошибка сохраняется, обратитесь в поддержку, указав *taskId* и полный запрос.

### `INVALID CHARACTER`
Код ошибки в API: `ERROR_PROXY_CREDENTIALS_INVALID_CHARACTER` <br />
Логин или пароль прокси содержит недопустимый символ %. Укажите учётные данные прокси без этого символа и повторите запрос.

### `NO FUNDS`
Код ошибки в API: `ERROR_ZERO_BALANCE` <br />
На счёте недостаточно средств для распознавания. [Пополните баланс](https://capmonster.cloud/SelectPaymentType) и повторите задачу.

### `BIG IMAGE SIZE`
Код ошибки в API: `ERROR_TOO_BIG_CAPTCHA_FILESIZE` <br />
Загруженное изображение превышает допустимый размер 50 KB. Уменьшите разрешение или сожмите файл, затем отправьте задачу снова. Ошибка встречается только в капчах с загрузкой изображения (*ImageToText, ComplexImageTask, ComplexImageTask Recaptcha* и т. д.).

### `ZERO IMAGE SIZE`
Код ошибки в API: `ERROR_ZERO_CAPTCHA_FILESIZE` <br />
Размер изображения слишком мал (менее 100 байт). Проверьте, что файл корректный и содержит изображение капчи.

### `CAPTCHA ID IS NOT FOUND`
Код ошибки в API: `ERROR_NO_SUCH_CAPCHA_ID`, `WRONG_CAPTCHA_ID` <br />
Проверьте значение `taskId`. Ошибка может возникнуть, если задача не существует, срок хранения результата истёк или идентификатор имеет некорректный формат. Повторный запрос с тем же `taskId` не даст результата.

### `CAPTCHA UNSOLVABLE`
Код ошибки в API: `ERROR_CAPTCHA_UNSOLVABLE` <br />
Не удалось решить CAPTCHA. Обычно это временная ошибка — попробуйте создать задачу повторно. Также проверьте корректность и актуальность параметров запроса.

Для CAPTCHA с изображениями повторяющиеся ошибки могут означать, что изображение невозможно корректно распознать: оно содержит слишком много шума, повреждено или не содержит ответа.

Нерешённые задачи не тарифицируются.

### `CAPTCHA IS NOT READY`
Код ошибки в API: `CAPTCHA_NOT_READY` <br />
Задача ещё находится в процессе решения. Повторите запрос [getTaskResult](./methods/get-task-result.mdx) позже, соблюдая интервал между запросами не менее 2 секунд.

### `REQUEST IS NOT ALLOWED FROM YOUR IP`
Код ошибки в API: `ERROR_IP_NOT_ALLOWED` <br />
Запрос с этого IP адреса с текущим ключом отклонен. Откройте раздел настроек в личном кабинете и [добавьте свой IP в список доверенных](https://dash.capmonster.cloud/Account/Settings).

### `IP BANNED`
Код ошибки в API: `ERROR_IP_BANNED` <br />
IP-адрес временно заблокирован из-за большого количества ошибочных запросов. Проверьте корректность отправляемых запросов и повторите попытку позже. Не отправляйте повторные запросы сразу после получения ошибки.

### `INCORRECT METHOD`
Код ошибки в API: `ERROR_NO_SUCH_METHOD` <br />
Указан некорректный тип задачи (параметр *type*). Проверьте список поддерживаемых [типов капчи](https://docs.capmonster.cloud/ru/docs/captchas) (значение параметра *type*).

### `REQUEST LIMIT EXCEEDED`
Код ошибки в API: `ERROR_TOO_MUCH_REQUESTS` <br />
Превышен допустимый лимит запросов. Увеличьте интервал между повторными запросами и попробуйте снова. При получении результата задачи вызывайте [getTaskResult](./methods/get-task-result.mdx) не чаще одного раза в 2 секунды.

### `THE DOMAIN IS NOT ALLOWED`
Код ошибки в API: `ERROR_DOMAIN_NOT_ALLOWED` <br />
Разгадывание капчи с некоторых доменов в CapMonster Cloud запрещено. При попытке создать задачу для таких доменов вы получите эту ошибку.

### `THE TOKEN IS EXPIRED`
Код ошибки в API: `ERROR_TOKEN_EXPIRED` <br />
Переданный токен или challenge устарел. Получите актуальное значение и создайте новую задачу. Повторная отправка задачи с теми же данными приведёт к той же ошибке.

### `INVALID RECAPTCHA SITEKEY`
Код ошибки в API: `ERROR_RECAPTCHA_INVALID_SITEKEY` <br />
Указан неверный *websiteKey*. Проверьте значение в коде страницы с капчей и передайте его корректно. Если у вас возникают трудности с поиском правильного ключа, пожалуйста, обратитесь в поддержку.

### `INVALID RECAPTCHA DOMAIN`
Код ошибки в API: `ERROR_RECAPTCHA_INVALID_DOMAIN` <br />
Домен не совпадает с указанным *sitekey*, либо параметр *websiteURL* передан в неверном формате. Указывайте полный URL страницы с капчей, включая протокол. **Поддерживаются только `http://` и `https://`.**

### `RECAPTCHA TIMEOUT`
Код ошибки в API: `ERROR_RECAPTCHA_TIMEOUT` <br />
Истекло время решения CAPTCHA. Создайте новую задачу. Если ошибка повторяется при использовании собственного прокси, проверьте его скорость и доступность или используйте другой прокси.

### `YOUR IP IS BLOCKED`
Код ошибки в API: `ERROR_IP_BLOCKED` <br />
Доступ с этого IP заблокирован из-за большого количества неудачных запросов. Проверьте параметры задач и ключ API перед повторной отправкой.

### `FAILED TO CONNECT PROXY`
Код ошибки в API: `ERROR_PROXY_CONNECT_REFUSED` <br />
Прокси-сервер отклонил подключение. Проверьте IP-адрес, порт и доступность прокси или используйте другой прокси.

### `THE PROXY IP IS BANNED`
Код ошибки в API: `ERROR_PROXY_BANNED` <br />
Указанный прокси заблокирован целевым сайтом. Используйте другой прокси.

### `MISSING PROXY`
Код ошибки в API: `ERROR_PROXY_MISSING`<br />
Не заданы параметры прокси в обязательных полях или указан некорректный *proxyType*. Укажите все обязательные параметры: *proxyType*, *proxyAddress*, *proxyPort*. Проверьте правильность значения *proxyType*.

### `PROXY NOT AUTHORIZED`
Код ошибки в API: `ERROR_PROXY_NOT_AUTHORISED`<br />
Неверные данные авторизации для прокси: *proxyLogin* или *proxyPassword*. Проверьте *proxyLogin* и *proxyPassword*. Убедитесь, что данные авторизации корректны и активны.

### `PROXY READ TIMEOUT`
Код ошибки в API: `ERROR_PROXY_READ_TIMEOUT`<br />
При работе через прокси истекло время ожидания ответа. Повторите запрос. Если ошибка возникает регулярно, проверьте доступность и стабильность прокси или используйте другой прокси.

### `INCORRECT TASK TYPE`
Код ошибки в API: `ERROR_TASK_NOT_SUPPORTED` <br />
Указанный тип задачи не поддерживается или задан некорректно. Пожалуйста, проверьте значение свойства type в объекте задачи.

### `TASK ABSENT`
Код ошибки в API: `ERROR_TASK_ABSENT` <br />
Объект task отсутствует в запросе [createTask](./methods/create-task.mdx) или JSON невалидный. Проверьте структуру запроса.

### `USERAGENT IS EXPIRED`
Код ошибки в API: `ERROR_WRONG_USERAGENT`<br />
В запросе указан невалидный User Agent. Ознакомиться с актуальным User Agent можно [здесь](https://capmonster.cloud/api/useragent/actual).

### `SERVICE NOT AVAILABLE`
Код ошибки в API: `ERROR_SERVICE_NOT_AVAILABLE`<br />
Сервис временно недоступен. Ошибка возвращается, если недоступен callback-сервис или не пройдена проверка доступности [getTaskResult](./methods/get-task-result.mdx). В этих случаях создание новых задач блокируется, чтобы пользователь не оплачивал задачи, результаты которых невозможно получить. Повторите запрос позже. Если используется callback, убедитесь, что указанный URL доступен.

### `INVALID TASK`
Код ошибки в API: `ERROR_INVALID_TASK`<br />
Запрос синтаксически корректен, но содержит некорректные данные для создания задачи. Например, обязательные поля отсутствуют, заполнены неверно или содержат устаревшие данные, из-за чего невозможно решить капчу. В `errorDescription` указывается, какие именно поля запроса некорректны и что нужно исправить. Проверьте параметры задачи, актуальность переданных данных и исправьте поля, указанные в `errorDescription`. Если самостоятельно устранить проблему не удаётся, пожалуйста, обратитесь в [службу поддержки](https://helpdesk.zennolab.com/ru/conversation/new).
