# getBalance : получение баланса

:::info Адрес метода
```http
https://api.capmonster.cloud/getBalance
```
формат запроса: `JSON POST`
:::

Для пользователей из России также доступен альтернативный адрес метода:

```http
https://ru.api.capmonster.cloud/getBalance
```

Он предназначен для снижения риска сетевых ошибок и блокировки запросов. При его использовании изменяется только адрес метода; параметры запроса, формат `JSON POST`, логика работы API и структура ответа остаются без изменений.

## Параметры запроса

### `clientKey`
Type: `String` <br />
Обязательный: `Да`<br />
Уникальный ключ вашей учетной записи

### Пример тела запроса

```json
{
  "clientKey": "API_KEY"
}
```

## Структура ответа

### `errorId`
Type: `Integer` <br />
Идентификатор ошибки.<br />**0** - ошибок нет, свойство *errorCode* отсутствует<br />**1** - ошибка, информация о ней находится в свойстве *errorCode*

### `errorCode`
Type: `String` <br />
Код ошибки. См. [глоссарий ошибок](../api-errors.mdx).

### `balance`
Type: `Decimal` <br />
Количество доступных средств на счёте

### Пример

```json
{
 "errorId":0,
 "balance": 345.678
}
```
