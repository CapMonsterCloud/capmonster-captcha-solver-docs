# Proton Captcha

<PriceBlockWrap>
  <PriceBlock title="Proton Captcha" captchaId="proton"/>
</PriceBlockWrap>

<McpNotice />

Proton Captcha — это система защиты, используемая в сервисах Proton для проверки легитимной активности пользователей и защиты от автоматизированных действий. Для решения этого типа капчи необходим прокси.

## Как найти HumanVerificationToken

1. Откройте страницу с Proton Captcha.
2. Откройте **Инструменты разработчика** (**F12** или правый клик → **Исследовать**).
3. Перейдите на вкладку **Network** и выполните действие, которое вызывает капчу.
4. Найдите запрос, в ответе которого содержится `HumanVerificationToken`.
5. Скопируйте значение токена и передайте его в поле `metadata.HumanVerificationToken`.

## Как найти pageAction

Параметр `pageAction` зависит от действия, выполняемого на сайте:
- Используйте `login` при входе пользователя в систему
- Используйте `signup` при создании новой учетной записи
