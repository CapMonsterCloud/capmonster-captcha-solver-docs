# HeyTap

HeyTap Captcha — это система безопасности, которая защищает веб-сайты от автоматизированных действий. Она анализирует поведение пользователя и генерирует токен для подтверждения легитимной активности.

## Как найти websiteKey

1. Откройте страницу с HeyTap Captcha.
2. Откройте **Инструменты разработчика** (**F12** или правой кнопкой мыши → **Просмотреть код**).
3. Перейдите на вкладку **Network** (Сеть) и перезагрузите страницу.
4. Найдите запрос к URL, содержащему API HeyTap captcha (обычно к `heytapmobi.com`).
5. Параметр `ak` в URL является `websiteKey`.

Также можно найти параметр в исходном коде страницы, поискав параметры инициализации или объекты конфигурации, связанные с HeyTap.

## Как найти apiServer

1. В **Инструментах разработчика** перейдите на вкладку **Network** (Сеть).
2. Найдите запросы к доменам, заканчивающимся на `heytapmobi.com`.
3. Скопируйте поддомен (например, `captcha-sec.heytapmobi.com`).
4. Передайте это значение в поле `metadata.apiServer` без префикса `https://`.
